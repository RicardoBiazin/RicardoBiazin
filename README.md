# Ricardo Biazin

Desenvolvedor Python e TypeScript. Crio ferramentas para Windows e aplicações web, do levantamento do problema até o deploy.

Desenvolvimento sob demanda: ferramentas desktop para Windows, aplicações web, integrações com APIs e automações.

## Stack

- **Linguagens:** Python, TypeScript, JavaScript, SQL
- **Desktop:** PySide6 (Qt), Tkinter, Win32 via ctypes, Electron
- **Web:** Next.js, Node.js, Supabase, Netlify, MapLibre, Three.js
- **Integrações:** APIs REST, OAuth2, FTP/FTPS, SFTP, S3, Azure, Google Cloud, OneDrive, Google Drive
- **Qualidade e segurança:** testes automatizados, Semgrep, SARIF, GitHub Actions

## Projetos em destaque

- **[nfse-nacional](https://github.com/RicardoBiazin/nfse-nacional)**: emissor de NFS-e Padrão Nacional em PySide6, com servidor para a rede local e DANFSe no navegador.
- **[sincronizador](https://github.com/RicardoBiazin/sincronizador)**: sincronização de pastas para Windows com 3 modos (espelho, incremental, bidirecional) e 13 destinos, de pasta de rede a S3 e Google Drive.
- **[raptor-win](https://github.com/RicardoBiazin/raptor-win)**: scanner SAST para Windows, sem Docker nem WSL, com saída SARIF e códigos de saída para CI.
- **[KitEscola](https://github.com/RicardoBiazin/KitEscola)**: comparador de preços de material escolar com frete por CEP e otimização de carrinho. Next.js em deploy na Netlify.
- **[RankingIA](https://github.com/RicardoBiazin/RankingIA)**: ranking de modelos de IA que junta quatro fontes em uma nota de 0 a 100, com atualização diária automática.
- **[multi-pc-kvm](https://github.com/RicardoBiazin/multi-pc-kvm)**: um teclado e um mouse para vários PCs Windows, com área de transferência compartilhada e tráfego cifrado.
